# マット運動 わざカード

小学3年生のマット運動の授業で使うWebアプリです。11の技それぞれについて、技名と技をしているイラストをカードで表示します。カードをタッチすると、お手本動画がアプリの中でそのまま再生されます。

## 使い方

- `index.html` をブラウザで開きます（タブレット・電子黒板・PCに対応）。
- カードをタッチすると動画ウィンドウが開き、動画が自動で再生されます。
- 「れんしゅう動画」のボタンを押すと、同じシリーズの練習動画に切り替わります。
- 「とじる」を押すか、ウィンドウの外をタッチすると閉じます。閉じると動画も止まります。

> YouTube の埋め込み動画は `file://` で直接開くと再生できないことがあります。GitHub Pages などWebサーバーに置いて使ってください。
> 手元で試すときは、このフォルダで `python3 -m http.server` を実行し、`http://localhost:8000/` を開きます。

ベネッセ教育情報チャンネルのマット運動動画は「前転・開脚前転・後転・側転」と、その練習・準備運動だけです。そのためアプリでは次のように扱っています。

- **倒立前転**：いちばん近い技の動画（前転のポイント）を「参考動画」として再生し、そのことを画面に表示します。
- **倒立ブリッジ**：「動画じゅんび中」と表示します。

## 動画の差し替え・追加

動画は `js/skills.js` で設定しています。

- 動画の一覧は、ファイル先頭の `V` にまとめてあります（`id` は YouTube URL の `watch?v=` の後ろ11文字）。
- 技ごとの設定は次のとおりです。
  - `video`：お手本動画
  - `related`：参考動画（`video` が無いときに再生）
  - `extra`：れんしゅう動画のボタン

たとえば頭倒立に動画を付けたいときは、`V` に `{ id: "動画ID", title: "タイトル" }` を追加して、頭倒立の `video:` に指定します。

## ファイル構成

```
index.html      画面
css/style.css   デザイン
js/figure.js    棒人間イラストを描く処理（SVG）
js/skills.js    技・イラストのポーズ・動画の設定
js/app.js       カード表示と動画ウィンドウ
```
